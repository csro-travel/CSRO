## 검증 범위

Windows Python 3.13에서의 서버 실행은 사용자의 PC에서 이어서 확인해야 합니다. wheel 다운로드 확인은 해당 플랫폼용 패키지를 설치할 수 있는지 확인한 것이며 Windows 런타임 검증은 아닙니다.

Spring의 실제 HTTP 호출·원문 저장·검증된 숙박일 채택·사건 생성, API-022 지연 회신 콜백, 영속 요청 원장·동시성, 공통 서버 배포, ML 시뮬레이터·학습은 이번 Mock 검증 범위에 포함하지 않습니다. `202`는 고정 대기 fixture이며 나중에 자동 완료되는 작업을 만들지 않습니다.

YB-002~005의 ID·호텔·기간은 명세 YB-001에 맞춰 확장한 구현용 fixture 선택입니다. 원문이 모든 추가 값을 확정했다고 설명하지 않습니다.
