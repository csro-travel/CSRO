## 해석과 범위

10월 검증 AP 기준으로 고정된 비교 권고는 XGBoost이며, 11~12월 테스트에서는 LightGBM의 AP·재현율·F1, XGBoost의 정밀도가 더 높았다. 테스트를 보고 권고·매개변수·라벨을 다시 조정하지 않았다. 원래 LightGBM 기준 모델을 교체하거나 배포하지 않았다.

이미 LightGBM 성능을 확인한 같은 합성 평가 구간을 이용한 후속 탐색 비교다. 새로운 독립 최종 검증, 실제 호텔 성능, 모델 도입의 인과적 효과를 확인한 실험은 아니다. 이번 실행은 CSV 사본의 무결성 확인과 모델 비교이며 원천 100호텔 전체 재생성이나 LightGBM 재학습을 수행한 기록이 아니다.

## 수치 오류의 경과

초기 71개 테스트는 통과했으나 실제 입력의 exposureRule 경계 점수가 Windows에서 동결 임계값보다 `5.551115123125783e-17` 작아 사전 검증이 중단됐다. 동일한 수식의 정확 유리수 계산으로 보완했고, 저장된 임계값·데이터·학습 설정·기존 core는 유지했다. 새 경계 회귀 2개를 포함한 위 73개 테스트와 실제 비교 실행으로 사용자 Windows 성공을 확인했다. 과거 실패 기록은 [비교 기록](../XGBOOST_COMPARISON.md)에 보존한다.
