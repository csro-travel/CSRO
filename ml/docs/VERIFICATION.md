## 일관된 코드와 실행 기록

첫 전체 실행은 병렬 구현의 마지막 통계 기록 수정과 겹쳐, 실행 도중 소스 해시가 달라져 자동 거부·폐기했다. 이후 핵심 생성 소스를 고정한 같은 매개변수로 다시 생성해 통과했다. 거부한 실행은 채택한 데이터나 모델에 사용하지 않았다.

최종 검토에서는 다른 실험 audit 결합 방지와 잘못된 CLI 입력을 보완했다. 생성 데이터·특성·학습 매개변수는 바꾸지 않았고 최종 코드로 모델 실행을 재현해 **동일한 checkpoint SHA-256과 평가 결과**를 확인했다. 생성 핵심 7개 모듈과 최종 학습/보고 모듈의 해시는 각 산출물 메타데이터와 일치한다.

ML 소스는 아직 사용자 Git 저장소에 커밋하지 않았다. 존재하지 않는 Git 커밋을 기록하지 않고 코드 SHA-256으로 추적했다. 제공한 코드와 파일럿/전체 생성·학습 원문 로그는 `verification/`에서 확인한다.
