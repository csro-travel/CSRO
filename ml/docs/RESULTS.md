# 실제 실험 결과 — ML v0.2 / seed 42

이 결과는 가상 사건 과정에서 생성한 관측 라벨에 대한 고정 실험이다. 실제 고객 장애율·실제 서비스 성능·AI 개입의 효과를 검증한 결과가 아니다.

## 데이터와 분할

| 항목 | 실제 값 |
| --- | ---: |

원천 예약·이벤트 수는 다른 채널, 2024년 준비 이력, 2026년 경계 buffer를 포함한다. 호텔·날짜 라벨 수와 같은 단위가 아니다. 1~3월 9,000행은 학습 구간에서 제외했고, 라벨 성숙 경계에서 학습 342행·검증 339행을 추가로 제거했다.

## 확인된 테스트 라벨에서의 비교

전체 11~12월 패널 6,100행 중 적격 6,005행, 확인 라벨 5,204행, UNKNOWN 801행, 빈 대상 95행이다. 적격 집합의 라벨 관측률은 86.66%다. 아래 지표는 확인된 5,204행(양성 84행, 1.61%)에서 계산했다. 분류 임계값은 각 모델의 10월 검증 F1로 선택하고 고정했다.

| 모델 | AP | ROC-AUC | Precision | Recall | F1 |
| --- | ---: | ---: | ---: | ---: | ---: |
| LightGBM | 0.4550 | 0.9282 | 0.7222 | 0.3095 | 0.4333 |
| 과거율+예약 수 규칙 | 0.3993 | 0.9180 | 0.7500 | 0.1786 | 0.2885 |
| 과거율 단독 참고 | 0.1492 | 0.8255 | 0.2588 | 0.2619 | 0.2604 |

AP는 sklearn의 average precision이며 다른 방식의 PR 곡선 적분값으로 바꾸어 부르지 않는다. LightGBM과 주 규칙의 AP 차이는 약 +0.0556이다. 이는 이 합성 실험의 점추정 비교이며 현실 성능 우위의 통계적 증명은 아니다.

## 일일 상위 10개 검토 대기열

UNKNOWN도 순위에서 자리를 차지한다. LightGBM은 61일×10개=610개를 선택했고, 그중 라벨 확인 456개·UNKNOWN 154개·확인된 양성 61개였다.

- 확인된 선택만의 precision: 13.38%
- 전체 선택을 분모로 한 precision 하한/상한: 10.00% / 35.25%
- 확인된 전체 양성 84개에 대한 recall: 72.62%

이 수치를 검증 F1 임계값에서의 Precision 72.22%·Recall 30.95%와 섞지 않는다. 선택 정책과 분모가 다르다. 관측률·범위는 평가 JSON에 모두 제공한다.

## 과거 장애율의 기여

검증 permutation AP 감소량 순서는 대상 예약 수(0.2954), 과거 장애율(0.2560), 재확인 지연(0.1407), 재고 부족 신호(0.1237), 성수기(0.0138), 유입 변화(-0.0005)였다. **과거 장애율은 2위였고 1위가 아니었다.** 순위를 맞추기 위해 데이터·정답·평가 구간을 바꾸지 않았다.

과거율 제거 후 같은 선택 구조로 재학습한 검증 AP는 0.4373, 전체 모델은 0.4477이었다. 다른 특성이 호텔 품질 신호를 공유하므로 marginal permutation 감소량과 특성 제거 재학습 차이는 같은 의미가 아니다. 과거율이 유용하다는 점과 다른 신호가 그 일부를 대체할 수 있다는 점을 함께 기록한다.

## 선택 모델과 해석 범위

- num_leaves=7, min_child_samples=30, best_iteration=43
- 모델은 4~9월 학습 checkpoint이며 학습+검증 재학습은 하지 않았다.
- 같은 가상 호텔의 미래 날짜 평가다. 신규 호텔 일반화 평가가 아니다.
- 고정된 수동 복구 정책 아래의 결과를 예측했다. 모델이 실제 고객 구제를 개선하는지 비교한 실험이 아니다.
- 점수는 위험 순위 신호이며 확률 보정이 입증된 값으로 표시하지 않는다.
- 원천 생성·증빙 유실·클래스 불균형·미확인 선택 편향 등 가정이 공유된 합성 학습/평가다.
- `audit_slices.json`은 호텔 규모·숨은 프로필·실제 원인·증빙 관측률 진단을 제공한다. 숨은 자료로 UNKNOWN 라벨을 채우거나 모델을 다시 선택하지 않는다.

최종 평가값과 checkpoint는 무결성 가드 보완 후 재실행에서도 동일했다. 이 재실행은 튜닝이나 새 독립 실험이 아니라 같은 설정의 재현성 확인이다.
